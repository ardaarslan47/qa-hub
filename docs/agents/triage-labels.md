# Triage label'ları

Skill'ler beş standart triage rolüyle konuşur. Bu dosya o rolleri, bu reponun issue tracker'ında kullanılan gerçek label adlarına eşler.

| mattpocock/skills'teki label | Bizim tracker'daki label | Anlamı                                     |
| ---------------------------- | ------------------------ | ------------------------------------------ |
| `needs-triage`               | `needs-triage`           | Maintainer'ın değerlendirmesi gerekiyor    |
| `needs-info`                 | `needs-info`             | Bildirenden ek bilgi bekleniyor            |
| `ready-for-agent`            | `ready-for-agent`        | Tamamen tanımlı, AFK agent için hazır      |
| `ready-for-human`            | `ready-for-human`        | İnsanın yapması gerekiyor                  |
| `wontfix`                    | `wontfix`                | Üzerinde çalışılmayacak                    |

Bir skill bir rolden bahsettiğinde (örneğin "AFK-ready triage label'ını uygula"), bu tablodaki karşılık gelen label adını kullan.

Gerçekte kullandığın adlar farklıysa "Bizim tracker'daki label" sütununu düzenle.
