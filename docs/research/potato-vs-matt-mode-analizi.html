8 · pstack'in kendi cevabı ve matt-mode v2

poteto-mode routing'ine göre 20 ticket'lık iş Feature değil: proje ölçeği → Orchestrate, bağımsız PR kuyruğu → Autopilot-full/stack. Run A'daki "tek owner" aslında hata değil; Feature playbook'u "code-coupled work goes to a single owner" diyor. matt-mode bunu doğru şekilde kaldırdı ama Feature'da kaldı.
